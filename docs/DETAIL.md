# 知识管理

在右侧 Sidebar 提供一个「知识管理」页，用于搜索、整理、同步知识，并让 Agent 在每轮对话中自动检索与记录知识点。

## 当前状态（阶段 0）

- 已注册侧栏 tab 类型 `knowledge` 与引导页入口，点开可见功能分区占位。
- 本地存储、检索、外部知识库连接、双向同步、备份、Agent 工具与提示词注入将在后续阶段接入。

## 规划中的模块

- 条目管理：关键词全文（中文 trigram）、按会话 / 标签表 / 时间范围 / 来源 / 敏感态筛选，相关度与时间排序。
- 新增记录：本轮新增按轮次查看，常规浅绿、敏感浅红。
- 疑似记录：待归类条目，可批量通过或设为敏感。
- 库管理与连接：主机 / 端口 / 用户名 / 密码 + 测试连接；高级设置每项带悬停说明。
- 同步与备份：待推 / 待拉计数、手动同步、备份列表与回滚。
- 已删除：墓碑列表与一键还原。
- 教学文档：部署步骤（Docker Compose / systemd）、连接步骤与排障。
- 统计：各库条数与体积、tier 与敏感分布、附件占用、修订与冲突数。

## 限制

- 仅 Desktop / Web 侧栏提供界面；CLI 不提供。
- 本地库使用内置 SQLite（`node:sqlite`），云端使用 MariaDB / MySQL，驱动 `mysql2` 随插件打包。
